## 📘 About

AutoIt is a BASIC-like scripting language created by Jonathan Bennett and maintained by the AutoIt community. It ships with a full script editor, a compiler that turns scripts into standalone executables, and a rich standard library for window control, process management, registry access, and GUI creation. The current release focuses on improved compatibility with Windows 11, updated built-in UDF libraries, and smoother SciTE editor performance on high DPI displays.

If you came looking for a AutoIt download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The installer is a standard Windows setup package and does not modify system files beyond registering the AutoIt interpreter and the optional SciTE editor.

**Good for:** system administrators · IT support technicians · QA automation testers · power users scripting desktop tasks · developers building small Windows GUI utilities · hobbyists learning scripting · classroom and lab environments

## 🧰 Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes immediately | Reboot Windows and run the setup file again from the Downloads folder. |
| Scripts do not run after install | Confirm the AutoIt interpreter path is registered and reopen the command prompt. |
| SciTE editor opens with tiny text | Adjust DPI scaling in the editor options under Tools, then SciTE Config. |
| Compiled EXE flagged by antivirus | Add the output folder to your antivirus exclusions through its own settings. |
| Installer reports missing runtime | Install the latest Microsoft Visual C++ Redistributable and retry setup. |
| Right-click context menu missing | Re-run the installer and enable the shell integration checkbox during setup. |
